# Bank Management System

A console-based banking project implemented in C++ that demonstrates:

- Customer and employee login
- Registration and account creation
- Deposit, withdrawal, and transfer operations
- Transaction history using a stack-based structure
- Service request handling using a queue-based structure
- Account storage and lookup using a binary search tree

## Build and Run

```bash
g++ -std=c++17 main.cpp -o bank_management_system
./bank_management_system
```

On Windows, you can run:

```powershell
g++ -std=c++17 main.cpp -o bank_management_system.exe
bank_management_system.exe
```
